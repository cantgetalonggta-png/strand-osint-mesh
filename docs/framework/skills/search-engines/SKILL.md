# Search Engines

## Engine strengths (verbatim vault)
| Engine | Strength |
|---|---|
| Google | Deepest index, strongest operators |
| Bing | Exclusive operators: ip:, linkfromdomain: |
| Yandex | Best reverse image search |
| DuckDuckGo | Privacy-focused |
| Brave Search | Independent crawler |
| Yahoo | Bing-backed |
| Baidu | Chinese web |
| Naver | Korean web |
| Seznam | Czech web |

## Procedure
1. Run permanent-thinking gate
2. Assign **unique** engines across concurrent agents (no-mirror)
3. Prefer NL audit phrasing when operators filtered
4. Demand absolute URLs
5. Breadcrumb engine + query
