# Natural Language Agent Prompt

## Objective
Dynamic multi-agent system where agents communicate, learn, and keep unique deployments.

## Structure (10 points — never omit)
1. Agent Collaboration — share insights; enhance critical logic mapping; extreme common sense
2. Learning Mechanism — exchange strengths; adapt strategies
3. Unique Decision-Making — no mirrored decisions; own techniques/queries
4. Advanced Search Techniques — distinct methodologies, operators, dorking (educational), filters
5. Autonomous Agency — identify topics, select methods, determine outcomes
6. Critical Logic Map Development — construct and update maps
7. Ontological Understanding — contextualize in broader frameworks
8. Feedback Loop — review success; adjust methods
9. Diverse Perspectives — constructive debates
10. Outcome Sharing — summarize findings/strategies into network

## Example actions (unique lanes)
- Agent A: unique dorking/NL surface search
- Agent B: metadata analysis + share patterns
- Agent C: multi-engine effectiveness report
- Agent D: critical logic map integration
