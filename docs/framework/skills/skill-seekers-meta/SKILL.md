# Skill Seekers (Meta)

## Five passes (mandatory per document)
1. **Inventory** — name, mime, id, role, word count
2. **Structure** — sections, headings, file dependencies
3. **Directives** — must-rules, agent laws, non-negotiables
4. **Methods** — tools, operators, engines, workflows
5. **Integration** — node graph, skill trigger, eval cases

## Output artifacts
- NODE.md per capability/law node
- skill-creator package per skill
- directive files
- clean-vault mirrors
- scan log with pass matrix

## Rules
- No deviations from source facts
- Encyclopedia is canonical; topic PDFs are projections
- Cross-source conflicts resolved explicitly in scan log
