# Archives & Ghost Indexes

## Archives
Wayback Machine · Archive.org · National Archives · Library of Congress · DOAJ

## Ghost index classes
orphaned directories · forgotten subdomains · unlinked pages · cached versions · removed content still indexed

## Procedure
1. Archive lookup for URL/domain
2. Compare to live
3. Tag ghost classes
4. Feed alteration + timeline
5. Breadcrumb

## Safety
Public archives only. Ghost classes are discovery labels, not exploit guides.
