# D02 — Hivemind No-Mirror

**Source:** hivemind Doc (verbatim)

## Rule
Agents and sub-agents hivemind and communicate while learning from each other, bouncing aspects and ideas, maintaining a critical logic map, extreme common sense, autonomous and ontological understanding — **and the system always has each individual agent and sub-agent choose their own separate individual action/deployment**.

## Enforcement
If two agents propose the same method on the same surface → block and reassign.
